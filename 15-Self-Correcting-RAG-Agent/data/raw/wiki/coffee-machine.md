# Kitchen Coffee Machine Guide

The bean-to-cup machine in the third floor kitchen needs its water tank refilled daily and its
bean hopper topped up when the low-bean light comes on. Facilities restocks the bean hopper
every Monday, but between restocks anyone can top it off from the bag in the cabinet above.

The machine runs a self-cleaning cycle automatically at 6am, so avoid using it right at opening
if you're in a hurry. A full descaling is scheduled monthly by facilities and takes about
twenty minutes -- there will be a sign taped to the machine when it's happening.

If the machine displays an error code, do not attempt to open the panel yourself; submit a
facilities ticket instead.
